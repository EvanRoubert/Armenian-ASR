# Armenian-ASR

State-of-the-art Automatic Speech Recognition (ASR) project for the Armenian language.

This project aims to develop a high-quality Automatic Speech Recognition (ASR) model for Armenian using large-scale speech data and modern self-supervised learning techniques.

## Status

🚧 **Research in progress.**

A large-scale speech corpus has already been collected and prepared for model development. The public audio dataset is available on Hugging Face:

* **Armenian Audio Dataset:** https://huggingface.co/datasets/Evanroubert/Armenian_audio

The current stage focuses on self-supervised pre-training, ASR model training, and evaluation.

The training code, model checkpoints, and technical documentation will be released after the initial research phase.

## Goals

* High-accuracy Armenian speech recognition
* Robust performance across different speakers and recording conditions
* Efficient training using modern SSL methods (HuBERT, Wav2Vec 2.0, WavLM)
* Open-source release of models, code, and documentation after the research milestone is completed
